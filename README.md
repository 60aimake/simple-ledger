# 지출 장부 틀

**60AI만들기** 채널에서 만든 무료 지출 장부입니다.
금액을 적으면 그 줄에 **영수증 폴더를 여는 링크**가 저절로 생깁니다.

👉 **https://60aimake.github.io/simple-ledger/**

## 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `지출장부_틀.xlsx` | 장부 한 장. 20줄 · 합계 자동 |
| `영수증폴더_만들기.bat` | R1 ~ R20 영수증 폴더를 한 번에 만듭니다 |

## 쓰는 법

1. 두 파일을 **같은 폴더**에 둡니다
2. `영수증폴더_만들기.bat` 을 한 번 실행합니다 → `영수증\R1` ~ `R20` 폴더가 생깁니다
3. `지출장부_틀.xlsx` 를 열고 금액을 적습니다
4. 그 줄에 **📁 R1** 같은 링크가 생깁니다. 누르면 그 번호의 영수증 폴더가 열립니다
5. 영수증 사진을 그 폴더에 넣어 두면 됩니다

## 확인한 것

- 한셀 ⭕ · 무료 오피스 ⭕ · 엑셀 ⭕ (2026-11-05 실측)
- 매크로가 없습니다. 보안 경고가 뜨지 않습니다
